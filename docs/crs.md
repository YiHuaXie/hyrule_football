# 竞彩足球比分玩法 (crs) 字段定义与玩法说明

## 玩法说明
- `crs` = Correct Score，即 **精确比分玩法**。
- 投注规则：
  - 预测比赛的最终比分，如 0:0、0:1、1:0、1:1、2:0 等。
  - sXXsYY 表示比分 X:Y 的赔率，例如 s00s01 = 0:1 的赔率。
  - sXXsYYf 表示对应赔率是否浮动，0=未变，1=变化。
  - 特殊字段：
    - s1sh: 半场主胜全场胜组合赔率  
    - s1sd: 半场主胜全场平组合赔率  
    - s1sa: 半场主胜全场客胜组合赔率  
- goalLine / goalLineValue：一般为空，仅让球玩法才有值
- updateDate / updateTime：赔率更新时间
