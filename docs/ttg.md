# 竞彩足球总进球玩法 (ttg) 字段定义与玩法说明

## 玩法说明
- `ttg` = Total Goals，即 **总进球数玩法**。
- 投注规则：
  - 预测比赛最终总进球数为 0、1、2、3、4、5、6、7+ 等。
  - sX 表示总进球数为 X 的赔率，例如 s0 = 总进球数为 0 的赔率。
  - sXf 表示对应赔率是否浮动，0=未变，1=变化。
- goalLine / goalLineValue：一般为空，仅让球玩法才有值
- updateDate / updateTime：赔率更新时间

## 字段定义

| 字段 | 含义 | 类型 | 备注 |
|------|------|------|------|
| goalLine | 让球盘口 | string | 一般为空 |
| goalLineValue | 让球数值 | string | 一般为空 |
| s0    | 总进球 0 赔率 | string | 示例: "17.00" |
| s0f   | 总进球 0 浮动标志 | int | 0=未变, 1=变化 |
| s1    | 总进球 1 赔率 | string | 示例: "6.50" |
| s1f   | 总进球 1 浮动标志 | int | 0=未变, 1=变化 |
| s2    | 总进球 2 赔率 | string | 示例: "3.85" |
| s2f   | 总进球 2 浮动标志 | int | 0=未变, 1=变化 |
| s3    | 总进球 3 赔率 | string | 示例: "3.60" |
| s3f   | 总进球 3 浮动标志 | int | 0=未变, 1=变化 |
| s4    | 总进球 4 赔率 | string | 示例: "4.10" |
| s4f   | 总进球 4 浮动标志 | int | 0=未变, 1=变化 |
| s5    | 总进球 5 赔率 | string | 示例: "7.75" |
| s5f   | 总进球 5 浮动标志 | int | 0=未变, 1=变化 |
| s6    | 总进球 6 赔率 | string | 示例: "13.00" |
| s6f   | 总进球 6 浮动标志 | int | 0=未变, 1=变化 |
| s7    | 总进球 7+ 赔率 | string | 示例: "18.50" |
| s7f   | 总进球 7+ 浮动标志 | int | 0=未变, 1=变化 |
| updateDate | 更新日期 | string | 示例: "2025-11-11" |
| updateTime | 更新时间 | string | 示例: "20:23:55" |
